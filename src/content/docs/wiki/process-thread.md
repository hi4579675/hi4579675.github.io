## 프로세스

실행 중인 프로그램. **독립된 메모리 공간**(code/data/heap/stack)을 가진다. 프로세스 간엔 메모리를 공유하지 않아 통신하려면 IPC가 필요.

## 스레드

프로세스 안의 실행 흐름. 같은 프로세스의 스레드들은 **code/data/heap을 공유**하고 **stack만 따로** 가진다.

| | 프로세스 | 스레드 |
|---|---|---|
| 메모리 | 독립 | heap 등 공유 |
| 생성 비용 | 큼 | 작음 |
| 통신 | IPC | 공유 메모리 |
| 한쪽 장애 | 격리됨 | 프로세스 전체 영향 |

## 멀티스레드의 함정

heap을 공유하니 여러 스레드가 같은 데이터를 동시에 건드리면 **race condition**이 생긴다. → 동기화(락, `synchronized`, atomic)가 필요하고, 과하면 데드락·성능 저하.

> 컨텍스트 스위칭은 스레드가 더 싸다(공유 자원이 많아 교체할 게 적어서). 그래서 동시성 작업은 보통 스레드 단위로.
